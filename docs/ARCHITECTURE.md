# Architecture
Next.js App Router serves protected UI and route handlers. Signed demo sessions derive tenant context server-side. `src/lib/repository/local.ts` serializes atomic JSON-file transactions for credential-free persistence; it is test/demo-only. Domain modules own strict vehicle/content/message schemas and deterministic scoring. The Supabase boundary is deliberately declared but not falsely implemented; PostgreSQL plus RLS remains production authority. Media, AI, messaging and video remain provider boundaries. The demo video result is a persisted inspectable storyboard status, not an MP4.
