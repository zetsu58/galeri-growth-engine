# Security
Implemented demo controls: signed HttpOnly/SameSite session, server-derived tenant context, strict Zod mutations, magic-byte/MIME/extension/5 MB upload checks, generated paths, atomic private state, message idempotency, safe JSON errors, correlation/security headers, redacting structured logger and replaceable in-memory rate limiter. React renders customer text as text. Corrective SQL adds composite tenant FKs and restricted functions. Production blockers: rotate mandatory session secret, Supabase JWT/RLS integration tests, CSRF origin protection, distributed rate limits, image decoder/re-encoding and object storage, raw Meta HMAC/replay controls, CSP nonce, malware scanning and penetration tests.
