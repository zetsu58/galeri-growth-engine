# Threat model
Assets include customer PII, inventory economics, messages, tokens and generated media. Actors include unauthenticated attackers, malicious tenants/files/messages and compromised providers. Principal threats: IDOR/cross-tenant reads (membership + RLS), SQLi (parameterization), XSS (text rendering/CSP), CSRF (same-site cookies/origin checks), SSRF (no user URLs; egress allowlist), upload polyglots/bombs (magic bytes/re-encode/limits), webhook replay/spoof (signature + unique event), prompt injection/data exfiltration (strict context/structured output/no tools), job exhaustion (quotas), secret/log leakage (redaction), and follow-up spam (consent/window/cancellation). Residual production risks require penetration tests, backup restore drills and provider review.
