# Threat model
Assets: PII, messages, inventory economics, tenant boundaries and provider credentials. Threats and controls: IDOR (session-derived scope + future RLS), SQLi (parameterized Supabase boundary), XSS (React text + CSP), CSRF (SameSite; production origin/token enforcement pending), SSRF (no remote upload URLs), traversal/MIME spoof/oversize files (generated path + extension/magic/limit; decoder/re-encode pending), webhook replay (persisted tenant/event uniqueness; Meta HMAC pending), prompt injection (customer data never becomes system/tool instruction), resource abuse (local rate limiter; Redis pending), and secrets/logs (environment only + redaction). Backups, restore drills, key rotation, egress policy and independent assessment remain production gates.
